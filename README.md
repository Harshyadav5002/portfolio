## 🎯 Overview

This is a **professional, fully responsive portfolio website** designed to showcase skills, projects, certifications, and achievements. Built with a **dark futuristic AI/ML aesthetic** featuring electric violet and neon cyan accents.

### Key Highlights:
- ✨ **Single HTML File** - No build process needed, easy to deploy
- 🎬 **Hero Video Background** - Large oval video with auto-play and controls
- 🎨 **Advanced Animations** - Smooth scroll reveals with GSAP + ScrollTrigger
- 📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile
- ⚡ **Performance Optimized** - Fast load times and smooth interactions
- ♿ **Accessible** - Semantic HTML with ARIA labels and focus styles
- 🎮 **Interactive Demo** - Live web demo of Online Examination System
- 🔧 **Easy to Customize** - All colors and content editable in one file

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- Optional: Simple HTTP server for best experience
- Optional: Git for version control

### Quick Start (No Installation)

1. **Download the Files**
   ```bash
   git clone https://github.com/Harshyadav5002/portfolio.git
   cd portfolio
   ```

2. **Open in Browser**
   - Double-click `index.html`, or
   - Drag and drop into browser window

3. **Best Experience (With Local Server)**
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Or using Node.js
   npx serve .
   
   # Or using PHP
   php -S localhost:8000
   ```
   Then open: `http://localhost:8000`

## 📦 Local Setup

### Option 1: Using Python
```bash
# Navigate to project folder
cd portfolio

# Start Python HTTP server
python -m http.server 8000
```

```bash
npm install -g serve

serve .

# Open browser (automatically or manually)
```

1. Open folder in VS Code
2. Install "Live Server" extension
3. Right-click on `index.html`
4. Select "Open with Live Server"
5. Browser opens automatically at `http://localhost:5500`

## 🌐 Deployment to GitHub Pages

### Step 1: Create GitHub Repository
```bash
# If not already done
git init
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to your GitHub repository
2. Click **Settings** → **Pages**
3. Under "Source", select:
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**
5. Wait 1-2 minutes for deployment

### Step 3: Access Your Portfolio
Your site will be live at:
```
https://YOUR_USERNAME.github.io/portfolio
```

### Step 4: Custom Domain (Optional)
1. In Settings → Pages, add your custom domain
2. Update DNS records with your registrar
3. Enable HTTPS

### Advanced Customization

#### 1. Modify Animations
GSAP animations are defined in the `loadAnims()` function (Lines 689-698):

```javascript
function loadAnims() {
  const tl = gsap.timeline({delay:0.12});
  tl.fromTo('#navbar', {y:-65, opacity:0}, {y:0, opacity:1, duration:0.55});
  // Modify duration, delay, or easing here
}
```

**Common Easing Functions:**
- `power1.out`, `power2.out`, `power3.out`
- `back.out`, `elastic.out`, `bounce.out`
- `cubic.out`, `sine.out`

#### 2. Adjust Particle System
Edit the particle initialization (Line 683):

```javascript
function initP(n=58) { // Change 58 to different particle count
  ps=[]; 
  for(let i=0;i<n;i++) ps.push(new P());
}
```

#### 3. Change Typography
Update font imports (Lines 11-12):

```html
<link href="https://fonts.googleapis.com/css2?family=Your+Font:wght@400;600;700&display=swap" rel="stylesheet">
```

Then update CSS variables:
```css
body { font-family: 'Your Font', system-ui, sans-serif; }
h1, h2, h3 { font-family: 'Your Font', system-ui, sans-serif; }
```

## 🐛 Troubleshooting

### Common Issues

**1. Video Not Playing**
- Ensure `hero-bg.mp4` is in the same folder as `index.html`
- Check browser console for errors
- Try a different video format (WebM, OGG)
- Increase video timeout

**2. Animations Not Working**
- Check GSAP library is loaded (open DevTools)
- Ensure JavaScript is enabled
- Try refreshing the page
- Clear browser cache

**3. Responsive Design Issues**
- Check media queries in DevTools
- Test on actual mobile device
- Verify viewport meta tag is present
- Check CSS is not cached

**4. Performance Issues**
- Reduce particle count in `initP()`
- Disable some animations
- Compress video further
- Use lighter font weights

**5. Deployment Issues**
```bash
# Clear GitHub Pages cache
# Wait 5-10 minutes for deployment
# Check repository settings
# Verify branch is set to main
```
