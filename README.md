# Harsh - Personal Portfolio

A stunning, production-grade single-file portfolio website built with vanilla HTML, CSS, and JavaScript.

## Features

- **Dark futuristic AI/ML aesthetic** with violet (#7c3aed) and cyan (#06b6d4) accents
- **GSAP + ScrollTrigger** for smooth, professional animations
- **Interactive particle background** in the hero
- **Custom cursor** with hover states
- **Live Web Demo** of the Online Examination System (fully functional quiz with timer)
- **3D tilt effects** on project cards
- **Animated skill bars** and count-up statistics
- **Fully responsive** (mobile, tablet, desktop)
- **Accessible** with proper ARIA labels and focus states
- **Production-ready** for GitHub Pages / Netlify / Vercel

## Getting Started

### Local Development

Simply open `index.html` in your browser:

```bash
# On Windows
start index.html

# Or use a local server (recommended)
npx serve .
# or
python -m http.server 8000
```

### Deploy to the Web

#### GitHub Pages (Free)

1. Push this folder to a GitHub repo
2. Go to repo **Settings → Pages**
3. Source: Deploy from a branch → `main` /root
4. Your site will be live at `https://<your-username>.github.io/<repo-name>`

#### Netlify / Vercel (Recommended)

1. Drag and drop the `Harsh_Portfolio` folder onto [Netlify Drop](https://app.netlify.com/drop) or Vercel
2. Done — instant global CDN + custom domain support

## Project Highlights

- **Hero Section**: Particle canvas + typewriter code card + staggered GSAP entrance
- **About**: Glassmorphic profile card with animated stats
- **Projects**: 4 cards with 3D mouse-tilt effect + one with a live interactive web demo
- **Skills**: Progress bars + tag clusters
- **Certifications**: Clean timeline-style cards
- **Contact**: Working form simulation + glowing contact cards

## Tech Stack Used

- HTML5 + CSS3 (Custom Properties + Glassmorphism)
- Vanilla JavaScript (no frameworks)
- GSAP 3 (animations + ScrollTrigger)
- Canvas API (particles)
- Fully semantic & accessible

## Customization

Edit `index.html` directly. All content, colors, and animations are in one file for simplicity.
